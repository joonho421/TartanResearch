# TartanResearch

A team-built research portal prototype developed for Carnegie Mellon University's 67-250 Information Systems course. It includes pages for exploring research opportunities and posting opportunities, with a Supabase integration.

This repository contains a copy of the project from the [original team repository](https://github.com/pnimmaga-jpg/67250_peopleproject_team1). The work was completed by the team; Joon Ho Song was a contributor. The original Apache 2.0 license is included.

## Explore the code

- [Home page](index.html)
- [Find research](find.html)
- [Post an opportunity](post.html)
- [Styles](style.css)
- [Email function](supabase/functions/send-email/index.ts)

Open `index.html` in a browser to view the frontend. The Supabase configuration points to the original team's backend; live data and posting features may depend on that service and its access settings.
